# Contributing

Useful contributions include reproducible audio/video timing fixes, runtime correctness, scene testing, input/save regressions and corrections to the English machine-translation draft.

For a bug report, include the supported title/version, build revision, CPU/GPU, the scene or last visible sentence, reproduction steps and a short relevant log. State whether the Japanese or English preview was used and whether another game instance was running. Remove personal paths and private data before posting logs.

Keep changes focused. Describe observed behavior, the reason for the change and the checks performed. Do not report presentation FPS alone as proof that audio or movie timing is correct.

For translations, use stable IDs, preserve script control tags and distinguish machine-generated drafts from human-reviewed text. Include an in-game layout check where possible.

Do not submit ISOs, decrypted executables, generated game code, assets, save files or complete original script dumps. Keep upstream ps3recomp notices intact. AI-assisted contributions are welcome; disclose substantial assistance and verify the result.
